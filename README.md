# Warfame Market Standing Efficiency Calculator

A web application for calculating the most profitable use of standing in *Warframe* based on current Warframe Market data and vendor offerings. The app helps players determine which items to purchase with earned standing in order to maximize platinum profit when sold on Warframe Market.

This project consists of:
- A **Go backend** for data aggregation, calculations, and API endpoints
- A **Svelte frontend** for the interactive UI
- Compose file including Nginx example

## Library

This project uses a library for the data aggregation logic [here](https://github.com/tylerolson/wfm-plat-efficiency).
